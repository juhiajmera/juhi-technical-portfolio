# Juhi Portfolio

## Folder structure

- `portfolio_app.py` - Streamlit application
- `juhi_architecture_diagrams/` - four architecture PNGs used by the project tabs

Keep the Python file and the image folder together. Do not move or rename the image files unless you also update `DIAGRAM_IMAGES` in the Python file.

## Run locally

```bash
pip install streamlit pandas plotly
streamlit run juhi_portfolio_app.py
```

The app uses the four supplied PNG diagrams directly.
